# mainapp-i-lab

## 项目简介

`mainapp-i-lab` 是一个用于归档和发布多个独立 HTML 页面的仓库。本仓库不针对任何特定域名或网站，旨在提供一个整洁、通用的静态页面存储空间，方便开发者或团队快速部署、分享或存档各类前端资源。

## 目录说明

```
mainapp-i-lab/
├── pages/          # 存放所有独立 HTML 页面
├── assets/         # 公共资源文件（样式、脚本、图片等，可选）
├── README.md       # 本文件
└── .gitignore      # Git 忽略规则
```

- **pages/**：每个子目录或文件名对应一个页面，建议按功能或项目命名。
- **assets/**：可放置页面间共享的 CSS、JavaScript、字体或图像文件。

## 页面归档说明

本仓库中的 HTML 页面均为独立可运行文件，彼此之间无依赖关系。每个页面均可通过直接打开或部署至静态服务器访问。

- 页面命名应清晰、简短，体现内容用途。
- 如有公共资源，请统一放置在 `assets/` 目录下，并在页面中通过相对路径引用。
- 建议在页面内注明版本或归档时间，便于日后回溯。

## 维护说明

- 新增页面：在 `pages/` 下创建新目录或文件，并更新本 README（如需）。
- 更新页面：直接修改对应 HTML 文件，注意保持向后兼容或记录变更。
- 删除页面：移除相关文件，并清理不再使用的公共资源。
- 提交信息：建议写明新增、修改或删除的页面名称及简要原因。

## 贡献

欢迎提交 Issue 或 Pull Request 来改进本仓库结构、添加通用资源或优化文档。请保持页面内容独立、整洁，避免引入外部不可控资源。
